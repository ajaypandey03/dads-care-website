# dadscare-chatbot-service

Chatbot service for Dad's Care's customers to ask about their godown status. Phase 1 is a **static, template-based Q&A bot** — no LLM: a fixed set of supported questions, each mapped to a fixed response template filled with live data pulled from `dadscare-backend`'s read-only APIs. An LLM-based free-form agent is an explicit later phase, not part of the initial build.

**Not started yet — this is a placeholder.**
